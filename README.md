# 📝 Менеджер задач PWA (Notes PWA App)

Прогрессивное веб-приложение (PWA) для управления задачами и заметками с поддержкой офлайн-режима, синхронизации в реальном времени через WebSocket и push-уведомлений.

Разработано в рамках курса "Фронтенд и бэкенд разработка" (РТУ МИРЭА, 4 семестр).

## 🚀 Особенности

*   **Офлайн-режим (Service Worker):** Приложение работает без интернета, кэшируя интерфейс и сохраняя данные в `localStorage`.
*   **Установка как приложение (Web App Manifest):** Можно установить на рабочий стол компьютера или смартфона, запускать в отдельном окне без рамок браузера.
*   **Синхронизация в реальном времени (WebSocket + Socket.io):** При добавлении задачи в одной вкладке, она мгновенно появляется во всех других открытых вкладках.
*   **Push-уведомления:** Системные уведомления о новых задачах даже если браузер свернут.
*   **Напоминания (Snooze):** Возможность установить напоминание на конкретное время. В уведомлении есть кнопка "Отложить на 5 минут".
*   **Архитектура App Shell:** Мгновенная загрузка интерфейса благодаря кэшированию каркаса приложения.

## ️ Технологический стек

*   **Backend:** Node.js, Express, Socket.io, Web-Push
*   **Frontend:** Vanilla JavaScript, HTML5, CSS3 (Chota UI framework)
*   **Database:** LocalStorage (клиентская база данных)
*   **Инфраструктура:** Service Workers, Web App Manifest

## 📦 Установка и запуск

### Предварительные требования
*   Установленный [Node.js](https://nodejs.org/) (версия 14+)
*   npm (поставляется вместе с Node.js)

### Шаги запуска

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ВАШ_НИКНЕЙМ/notes-pwa-app.git
    cd notes-pwa-app
    ```

2.  Установите зависимости:
    ```bash
    npm install
    ```

3.  **Генерация VAPID ключей (для Push-уведомлений):**
    Выполните команду:
    ```bash
    npx web-push generate-vapid-keys
    ```
    Скопируйте полученный `Public Key` и `Private Key`.

4.  **Настройка конфигурации:**
    Откройте файл `server.js` и замените заглушки на ваши ключи:
    ```javascript
    const vapidKeys = {
      publicKey: 'ВСТАВЬТЕ_СЮДА_ПУБЛИЧНЫЙ_КЛЮЧ',
      privateKey: 'ВСТАВЬТЕ_СЮДА_ПРИВАТНЫЙ_КЛЮЧ'
    };
    ```
    Также откройте файл `app.js` и найдите функцию `subscribeToPush`. Замените ключ в строке:
    ```javascript
    applicationServerKey: urlBase64ToUint8Array('ВСТАВЬТЕ_СЮДА_ПУБЛИЧНЫЙ_КЛЮЧ')
    ```

5.  Запустите сервер:
    ```bash
    node server.js
    ```

6.  Откройте браузер по адресу:
    ```
    http://localhost:3001
    ```

## 🧪 Как тестировать функционал

1.  **Офлайн-режим:**
    *   Откройте DevTools (F12) -> Network -> выберите "Offline".
    *   Обновите страницу. Она должна загрузиться из кэша.
    *   Попробуйте добавить заметку. Она сохранится локально.

2.  **WebSocket (Real-time):**
    *   Откройте приложение в двух разных вкладках.
    *   В первой вкладке добавьте задачу.
    *   Во второй вкладке мгновенно появится всплывающее уведомление.

3.  **Push-уведомления и Напоминания:**
    *   Нажмите зеленую кнопку "Включить уведомления" и разрешите их в браузере.
    *   Заполните форму "Напоминание": введите текст и выберите время на 1-2 минуты вперед.
    *   Сверните браузер или переключитесь на другую вкладку.
    *   Через указанное время придет системное уведомление Windows/macOS.
    *   В уведомлении будет кнопка **"Отложить на 5 минут"**. При нажатии уведомление исчезнет и вернется через 5 минут.

4.  **Установка PWA:**
    *   В адресной строке Chrome справа появится значок "Компьютер со стрелкой вниз".
    *   Нажмите его и выберите "Установить". Приложение откроется в отдельном окне.
